# SCHEMA

- schema in dbms defines the overall structure of the database
    - it defines how the data is organized, how different elements are related to each other and rules that govern them
- database schema is the formal blueprint or structural framework that defines how data is organized, stored, and related within a database management system (DBMS). 

- It acts like a building's architectural plan: it does not contain the actual data itself, but rather establishes the rules, tables, fields, and relationships that the data must follow

- A schema is divided into three levels of abstraction to isolate users from the hardware
    - Physical Schema
        - lowest level
        - defines how data is physically stored in the memory
    - Logical Schema
        - middle level
        - It defines the structure of the tables, columns, keys and data relationship
    - View Schema
        - highest level
        - This defines what the end-users will see
