# DATABASE

- Database is an organised collection of data.
    - Database can be considered as a method to access and manipulate the data.

### why not excel, google sheet
- can store only a limited amount of data
- if data goes beyond this limit, efficiency gets finished

### Database VS DBMS (Database Management System)

- A website is connected to Database 
    - A DBMS is the bridge / connector between website and database
    - A DBMS manages the Database
    - DBMS enables the users and applications to interact with the database
    - Ex of DBMS are PostgreSQL , MySQL , Oracle

### RDBMS (Relational Database Management System)

- It is a type of database management system that stores the data in structured tables(using rows and columns) 
- uses SQL (structured query language) for managing and querying data

### SQL (Structured Query Language)

- it is language that is used to access, manipulate and query the database
