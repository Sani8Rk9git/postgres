# Order by clause

- It is used for sorting of data according to the values of a column.

```
SELECT * FROM employees
ORDER BY salary;
```
- this arranges the data in the increasing order of the salaries.

```
SELECT * FROM employees
ORDER BY fname;
```
- For the strings it arranges in the a-z order.
- ORDER BY by default arranges the data in ascending order

```
SELECT * FROM employees
ORDER BY dept DESC;
```
- To arrange in the descending order, add DESC
